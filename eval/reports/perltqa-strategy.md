## 策略 1：身份问句抬职业和头衔

问句是「某人是谁 / 是什么人 / 什么身份 / 是做什么」，或只有名字加「是什么」，并且问的名字出现在「的职业是 / 的头衔是」这张短卡片里时，把这张卡片抬到当前最高分之上 0.01 到 0.02。问的是别人（卡片里没有这个名字）时不抬。

结果（`perltqa-full-identity-gated.json`）：

- Recall@5 0.9330 → 0.9341
- MRR 0.8186 → 0.8188
- 未进前 5：575 → 566
- 排名 20 名之后：96 → 88
- 档案 Recall@5 0.7591 → 0.7843
- 修好 7 条，没有新增失败。包括「梁欣是谁？」从第 84 名到第 1 名。

社会关系、事件、对话的 Recall@5 没有变化。

## 策略 5：关系问句按词切开，并抬出「是某人」的短关系卡

## 策略 6：介绍某人、以及没有职业卡的「某人是谁 / 是做什么」

问句是「介绍一下 / 描述一下某人」，或句首是「某人是谁 / 是什么人 / 是什么关系 / 是做什么 / 是干什么 / 是什么角色 / 是什么行业」时，如果这个人没有自己的「的职业是 / 的头衔是」卡片，就把含「是某人。」或「是某人，」且不超过 220 字的短关系卡抬到当前最高分之上。已经有职业或头衔卡的人不再抬，避免把档案卡压下去。
